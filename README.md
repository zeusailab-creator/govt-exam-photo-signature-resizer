# ⚡ SarkariPhotoFix - Free Govt Exam Photo & Signature Resizer

> **Live Web Application**: [https://sarkariphotofix.com/](https://sarkariphotofix.com/)

A lightweight, 100% client-side web utility engineered to eliminate document rejection across Indian government exam portals (SSC, UPSC, Railway RRB, India Post GDS, State Police, and Defence rallies).

## 🚀 Key Features

- **Strict Portal Calibrations**:
  - **SSC GD / CGL / CHSL**: Photo (20–50 KB, 3.5×4.5 cm), Signature (10–20 KB, 140×60 px).
  - **India Post GDS**: Dedicated [GDS 5:2 Aspect Ratio Signature Resizer](https://sarkariphotofix.com/gds-signature-resizer) (140×60 px, 10–20 KB).
  - **Railway RRB (ALP, NTPC, Group D)**: Photo (30–70 KB), Signature (10–20 KB).
  - **UPSC & State PSCs**: 350×350 px square calibration.
- **Auto Paper Background Whitener**: Converts dirty mobile camera shadows on white paper into pure `#ffffff` background with high-contrast ink boost via [Signature Whitener](https://sarkariphotofix.com/signature-whitener).
- **Sarkari Bio Data Maker**: 1-Click printable 1-page A4 PDF bio-data generator for Army Agniveer rallies and Police walk-ins via [Sarkari Bio Data Maker](https://sarkariphotofix.com/biodata-maker).
- **Cyber Cafe Operator Mode**: Batch multi-file processing (5–20 candidates at once) with 1-click ZIP export via [CSC Operator Mode](https://sarkariphotofix.com/csc-operator-mode).
- **Embeddable Widget**: Free iframe widget for educational bloggers and job portals via [Embed Widget](https://sarkariphotofix.com/embed-widget).

## 🔒 Privacy & Architecture

Unlike traditional converters that upload candidate photos to remote cloud servers, **SarkariPhotoFix processes 100% of images locally inside the browser** using HTML5 Canvas API and JavaScript. Zero images or candidate details are ever stored or uploaded.
